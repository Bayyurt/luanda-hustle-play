# Luanda Hustle — jogar no browser

Protótipo jogável: https://bayyurt.github.io/luanda-hustle-play/

- Computador: teclado WASD; E para entrar/interagir; P para pausar.
- Telemóvel: usar na horizontal; os controlos tácteis aparecem automaticamente.
- A primeira abertura descarrega os ficheiros do jogo; aguarda o carregamento.

Este repositório contém apenas a distribuição Web exportada do Godot. O repositório de desenvolvimento e o seu histórico continuam privados.

Versão de teste: há problemas de tráfego conhecidos; desempenho em dispositivos físicos ainda em validação. A distribuição não é uma declaração de que o jogo está concluído. Os créditos/licenças dos recursos mantêm-se no jogo e no pacote exportado.
